# 웹툰 TTS 리더 (테스트판)

웹툰을 라디오처럼 들려주는 개인 감상용 도구예요.
"웹툰 캐릭터별 TTS 리더 프로젝트" 문서의 **1단계 테스트 계획**을 PC 브라우저용으로 만든 버전이에요.

```
웹툰 이미지 → Claude가 말풍선 대사·화자·읽는 순서 추출 → 캐릭터별 목소리로 읽기 → 읽는 위치로 자동 스크롤
```

## 실행 방법

1. 이 폴더의 `index.html`을 **크롬**이나 **엣지**로 열어요. 파일을 브라우저 창에 끌어다 놓아도 돼요.
2. 설치할 것은 없어요. 인터넷만 연결돼 있으면 돼요.

## 사용 순서

| 단계 | 하는 일 |
| --- | --- |
| 1. 웹툰 불러오기 | 이미지 파일을 여러 장 고르거나 샘플 버튼을 눌러요. **쉬운 샘플**은 캐릭터 3명이 나오는 10컷 웹툰이에요. **어려운 샘플**은 아래 "복잡한 웹툰 대응"에 나온 상황을 모아 놓은 9컷 웹툰이에요. 둘 다 정답지가 함께 만들어져요. |
| 2. 대사 분석 | Claude API 키를 넣고 **대사 분석 시작**을 눌러요. 중간에 **분석 멈추기**를 누르거나 오류가 나도 **이어서 분석**으로 끝난 곳부터 다시 할 수 있어요. API 없이 먼저 들어 보려면 **정답지로 바로 듣기**를 눌러요. |
| 3. 캐릭터 목소리 | 캐릭터마다 목소리, 높낮이, 빠르기를 정하고 🔊로 미리 들어요. 이름 칸을 고치면 그 화자의 대사 전체에 적용돼요. 같은 이름으로 바꾸면 두 캐릭터가 하나로 합쳐져요. |
| 4. 듣기 | ▶ 재생을 누르면 대사를 읽으면서 화면이 따라 내려가요. 대본이나 그림 속 번호를 누르면 그 대사부터 읽어요. |
| 5. 정답지와 비교 | 분석 결과가 얼마나 맞았는지 대사 찾기, 글자, 화자, 읽는 순서별 점수로 보여 줘요. |

### 정답지 형식

JSON 파일(샘플 정답지 저장으로 받은 파일), 또는 아래처럼 쓴 텍스트 파일(.txt)을 쓸 수 있어요.

```
민지: 준호 오빠! 빨리 일어나!
준호: 으음… 오 분만 더…
토요일 아침, 민지네 집
```

`화자:`가 없는 줄은 나레이션으로 처리해요.

## 알아 둘 점

- **API 키와 요금**: [Claude Console](https://platform.claude.com)에서 API 키를 만들어요. 분석할 때마다 요금이 나가요. 샘플 2장(조각 4개) 분석은 보통 1달러 이하예요. 화면에 사용 토큰과 대략적인 금액이 표시돼요. 한 번 분석한 결과는 **분석 결과 저장**으로 저장해 두고 다음에 불러오면 다시 요금이 들지 않아요.
- **API 키 보관**: 키는 내 브라우저에서 Claude 서버로만 보내져요. "키 기억하기"를 켜면 이 컴퓨터 브라우저에 저장되니 내 컴퓨터에서만 켜세요.
- **목소리 개수**: 목소리는 브라우저에 들어 있는 TTS를 써요. 한국어 목소리가 1~3개뿐인 경우가 많아서, 높낮이와 빠르기를 다르게 해서 캐릭터를 구분해요. 엣지는 자연스러운 한국어 목소리를 더 많이 제공해요.
- **저작권**: 남의 웹툰은 개인 감상용으로만 쓰고, 결과를 녹음해서 올리지 마세요.

## 복잡한 웹툰 대응

| 상황 | 처리 방법 |
| --- | --- |
| 세로로 아주 긴 이미지, 여러 장으로 나뉜 회차 | 모든 이미지를 같은 폭으로 맞춰 하나의 긴 띠로 이어 붙여요. 그다음 1400px 조각으로 400px씩 겹쳐서 잘라 분석해요. |
| 파일 경계에 걸려 잘린 말풍선 | 띠로 이어 붙인 뒤 자르기 때문에 한 조각 안에서 온전히 보여요. |
| 겹친 부분에서 같은 말풍선이 두 번 나올 때 | 글자가 75% 이상 비슷하면 한 번만 써요. 글자를 조금 다르게 읽어도 걸러져요. |
| 폭이 다른 이미지, 너무 작거나 큰 이미지 | 분석할 때 폭을 700~800px로 맞춰요. |
| 나중에 이름이 밝혀지는 인물 | 처음엔 "인물A"로 부르다가, 이름을 알게 되면 앞 대사까지 모두 진짜 이름으로 바꿔요. |
| 화자 일관성 | 조각마다 지금까지 나온 인물 목록과 바로 앞 대사 8개를 함께 보내요. |
| 화면 밖 목소리 | 앞뒤 대사로 누구인지 추측하고, 모르면 "화면 밖 목소리"로 적어요. |
| 효과음, 간판 같은 배경 글씨 | 따로 구분해서 기본으로는 읽지 않아요. 체크하면 읽어요. |
| ㅋㅋ, ㅎㅎ, ㅠㅠ, ~, …, ?!?! | 화면 글자는 그대로 두고, 소리로 읽을 때만 "크크크", "흐흐"처럼 다듬어요. 읽을 글자가 없는 "…"는 잠깐 쉬고 넘어가요. |
| 긴 대사 | 문장 단위로 나눠 읽어요. 크롬이 긴 문장을 읽다 멈추는 문제를 피하려는 거예요. |
| 일시적인 서버 오류, 깨진 답변 | 조각마다 최대 3번 다시 시도해요. |

## 사용한 기술

- Claude API (`claude-opus-5-5`, 공식 TypeScript SDK를 브라우저에서 사용): 이미지 분석과 구조화된 JSON 출력
- 브라우저 Web Speech API: 음성 읽기 (무료)
- HTML 파일 하나로 이루어져 있어요.
